CODEX SENTINEL for Magpie

登录账号检测台

使用部署时配置的访问密钥登录，无需注册或输入用户名。

用 Magpie 的哪个密钥？

沿用 Magpie 网页访问密钥时，请输入 Docker 部署配置中的 MAGPIE_WEB_KEY 的值。

这是打开 Magpie 网页时使用的固定访问密钥。不要填写模型 API 的网关密钥或 Codex 账号密码。

填写密钥的实际内容，不是文字“MAGPIE_WEB_KEY”。

找不到密钥，或使用了独立密码？

已有带密钥的链接？直接打开管理员提供的 /?k=访问密钥 链接即可进入，验证后地址栏会自动清除密钥。

自己部署：在部署 Magpie 的 compose.yaml、docker-compose.yml 或对应的 .env 中，查找 MAGPIE_WEB_KEY 的配置值。

他人部署：向管理员索取此检测台的访问密钥。如果管理员为 Sentinel 单独设置了密码，请使用该密码。

本机插件默认免登录；只有开启远程访问保护后才会显示此页。

登录有效期 12 小时 · 检测记录保存在运行服务的机器上
